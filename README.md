# ScopeGuard

AI Agent Security & Runtime Protection

## Overview

ScopeGuard is an AI-powered runtime security system
designed to monitor AI agent activities, detect
unauthorised actions and enforce task-based permissions.

## Problem

AI agents can interact with files, execute commands
and access external services. Malicious instructions
can manipulate their behaviour and cause unintended actions.

## Proposed Solution

ScopeGuard compares an AI agent's actual activities
with its intended task and detects actions that
exceed the permitted scope.
